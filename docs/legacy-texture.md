# Legacy enchanted golden apple texture

The 16 × 16 PNG is the unmodified `assets/minecraft/textures/item/golden_apple.png`
from Mojang’s built-in Programmer Art resource pack. Vanilla uses the same base sprite for
ordinary and enchanted golden apples; the enchantment glint is rendered by the game.
This mod selects the legacy model only for enchanted golden apples.

- Official explanation: https://www.minecraft.net/en-us/article/village---pillage-out-java-
- Pack: `minecraft/resourcepacks/programmer_art.zip` from the Minecraft 26.2 asset index.
- Official asset URL: https://resources.download.minecraft.net/bd/bde50ccdd1e00729f4d187c8ff25ebed357a761a
- Pack SHA-1: `bde50ccdd1e00729f4d187c8ff25ebed357a761a` (verified before extraction).
- Output: `assets/overpowered_again/textures/item/enchanted_golden_apple_legacy.png`.
